# Touch Sensor Piano — ESP32 Touch Piano Prototype

ESP32의 정전식 터치 입력으로 네 음(C4, D4, E4, G4)을 연주하는 하드웨어 테스트 스케치입니다. 각 터치 패드는 음과 RGB 색상에 연결되어 있고, 별도 버튼으로 짧은 테스트 멜로디를 재생합니다.

> 이 스케치는 프로젝트의 Emotion Piano 인터랙션을 시험하는 프로토타입입니다. 감정을 자동으로 인식하거나 분류하는 기능은 포함되어 있지 않습니다.

## 기능

- ESP32 터치 입력 4개로 C4, D4, E4, G4 연주
- 부팅 시 각 터치 입력의 기준값을 자동 측정
- 기준값의 70% 미만을 터치로 판정
- 터치한 음에 맞춰 RGB LED 색상 변경
- 버튼을 누르면 C–D–E–G 테스트 멜로디 재생
- 시리얼 모니터에 음 이벤트와 원시 터치값 출력
- 터치가 없을 때 부저를 끄고 LED를 약한 파란색으로 설정

## 하드웨어

- 클래식 ESP32 계열 개발 보드
- 금속 포일, 구리 테이프 등으로 만든 정전식 터치 패드 4개
- Passive buzzer
- RGB LED와 채널별 전류 제한 저항
- 순간 누름 버튼
- 브레드보드 및 점퍼 와이어

이 핀 구성은 GPIO 4, 27, 32, 13에서 `touchRead()`를 지원하는 클래식 ESP32를 기준으로 합니다. ESP32 제품군마다 터치 핀과 API가 다를 수 있으므로 보드 모델에 맞는 핀맵을 확인하세요.

## 핀 연결

| 부품           | ESP32 GPIO | 기능                          |
| -------------- | ---------: | ----------------------------- |
| 터치 패드 C    |          4 | C4, 262 Hz                    |
| 터치 패드 D    |         27 | D4, 294 Hz                    |
| 터치 패드 E    |         32 | E4, 330 Hz                    |
| 터치 패드 G    |         13 | G4, 392 Hz                    |
| RGB LED 빨강   |         14 | C 음 표시                     |
| RGB LED 초록   |         25 | D 음 표시                     |
| RGB LED 파랑   |         18 | E 음 표시                     |
| Passive buzzer |         26 | 음 출력                       |
| 버튼           |         23 | 테스트 멜로디, 내부 풀업 사용 |

### 배선 참고

- 터치 패드는 각 지정 GPIO에 연결하고, 터치 영역을 넓히려면 전도성 재료를 사용합니다. 터치 전극이 서로 닿지 않도록 분리하세요.
- 부저는 GPIO의 허용 전류와 모듈 사양을 확인해 연결합니다. 부하가 큰 부저는 트랜지스터 드라이버를 사용하세요.
- RGB LED 각 채널에는 전류 제한 저항이 필요합니다. 현재 코드는 PWM 값이 커질수록 해당 채널이 밝아지는 공통 음극형 논리를 가정합니다. 공통 양극형이면 `setColor()`의 PWM 값을 반전해야 할 수 있습니다.
- 버튼 한쪽을 GPIO23, 다른 쪽을 GND에 연결합니다. `INPUT_PULLUP` 설정이므로 눌렀을 때 `LOW`가 됩니다.
- ESP32와 주변 장치의 GND를 공통으로 연결하세요.

## 준비 및 실행

1. Arduino IDE에서 ESP32 보드 지원 패키지를 설치합니다.
2. 위 표대로 터치 패드, 부저, RGB LED, 버튼을 연결합니다.
3. Arduino IDE에서 보드와 포트를 선택하고 스케치를 업로드합니다.
4. 부팅 시 LED·부저 시작 테스트 후 터치 기준값 보정이 진행됩니다.
5. 시리얼 모니터를 **115200 baud**로 엽니다.
6. `DO NOT TOUCH THE TOUCH WIRES!`가 표시되는 보정 시간에는 터치 패드를 만지지 마세요.
7. `READY`가 표시되면 각 패드를 터치해 음과 색상 반응을 확인합니다.
8. GPIO23 버튼을 눌러 테스트 멜로디를 재생합니다.

## 터치 판정과 음 처리

부팅 후 약 2초 동안 패드를 건드리지 않도록 안내하고, 각 입력을 30회 샘플링해 평균 기준값(`baseC` 등)을 계산합니다. 실행 중 입력값이 기준값의 70%보다 낮으면 터치로 판정합니다.

| 터치 | 음  | 주파수 | LED 색상 |
| ---- | --- | -----: | -------- |
| C    | C4  | 262 Hz | 빨강     |
| D    | D4  | 294 Hz | 초록     |
| E    | E4  | 330 Hz | 파랑     |
| G    | G4  | 392 Hz | 노랑     |

음은 터치가 새로 시작되는 순간에 재생됩니다. `else if` 구조이므로 같은 루프에서 여러 패드가 동시에 새로 눌리면 C, D, E, G 순서로 우선 처리됩니다. 여러 음을 동시에 연주하는 화음 기능은 구현되어 있지 않습니다. 모든 패드에서 손을 떼면 부저를 끄고 LED를 약한 파란색으로 되돌립니다.

## 조정 가능한 값

- 핀 번호: `#define TOUCH_*`, `LED_*`, `BUZZER_PIN`, `BUTTON_PIN`
- 음높이: `NOTE_C4`, `NOTE_D4`, `NOTE_E4`, `NOTE_G4`
- 민감도: `touchRatio` (현재 `0.70`)
- RGB 색상 및 대기색: `setColor()` 호출부
- 버튼 멜로디 길이: `playTestMelody()` 안의 `delay()` 값

## 문제 해결

| 증상                                      | 확인할 항목                                                                                |
| ----------------------------------------- | ------------------------------------------------------------------------------------------ |
| 터치가 계속 감지되거나 전혀 감지되지 않음 | 부팅 보정 중 패드를 만지지 않았는지, 기준값과 원시값, `touchRatio`, 보드 터치 핀 지원 여부 |
| 터치가 불안정함                           | 터치 전극 배선 길이, 주변 노이즈, 패드 간격, 접지 상태                                     |
| LED 색상이 다르게 보임                    | RGB 채널 순서와 공통 양극/음극 유형, 저항 및 배선                                          |
| 버튼이 눌린 상태로 인식됨                 | GPIO23과 GND 연결, 버튼 배선, `INPUT_PULLUP` 설정                                          |
| 테스트 멜로디 중 입력이 멈춤              | `delay()` 기반의 블로킹 재생이므로 멜로디 중에는 터치 처리가 일시 정지됩니다.              |
