# IR Invisible Tripwire

ESP32로 38 kHz 적외선 빔을 송신하고 수신 상태를 감시하는 비접촉식 경보 프로토타입입니다. 빔이 차단되면 RGB LED가 빨간색으로 바뀌고 Active/Passive 부저가 경고음을 냅니다. 빔이 복구되면 초록색 대기 상태로 돌아옵니다.

## 기능

- 38 kHz IR 신호를 짧은 측정 구간 동안 송신
- 수신기 출력이 LOW인 경우 빔 감지로 판정
- 빔 연결에서 차단으로 바뀌는 순간에만 경보 발생
- 차단 상태에서 빨간색, 복구 상태에서 초록색 LED 표시
- Active buzzer와 Passive buzzer를 이용한 경고음
- 시리얼 모니터에 차단 및 복구 이벤트 출력

## 준비물

- ESP32 계열 보드
- 38 kHz IR 수신 모듈(디지털 출력형)
- IR 송신 LED 및 적절한 전류 제한 저항
- Active buzzer와 Passive buzzer
- RGB LED 및 각 채널 전류 제한 저항
- 점퍼 와이어와 브레드보드

핀 구성과 `tone()` 사용은 ESP32 계열을 가정합니다. 사용하는 보드와 Arduino core에서 해당 API 및 핀을 지원하는지 확인하세요.

## 핀 연결

| 부품                  | ESP32 GPIO | 역할                          |
| --------------------- | ---------: | ----------------------------- |
| IR 송신 LED           |         18 | 38 kHz 신호 출력              |
| IR 수신기 디지털 출력 |         27 | 빔 수신 상태 입력             |
| Active buzzer         |         26 | 경고 중 ON/OFF                |
| Passive buzzer        |         25 | 1 kHz와 1.8 kHz 경고음        |
| RGB LED 빨강          |         23 | 빔 차단 표시                  |
| RGB LED 초록          |         17 | 대기·빔 복구 표시             |
| RGB LED 파랑          |         16 | 현재 스케치에서 사용하지 않음 |

IR 수신기는 IR 신호를 감지할 때 출력이 `LOW`가 되는 모듈을 전제로 합니다. 수신기 모듈의 출력 극성이 반대라면 `checkIRBeam()`의 판정을 조정하세요.

### 배선 주의

- IR 송신 LED는 GPIO에서 직접 큰 전류를 끌어오지 않도록 부품 정격과 저항을 확인하세요. 송신 거리가 부족하거나 LED 전류가 큰 경우 트랜지스터 드라이버를 사용합니다.
- RGB LED 각 채널에 전류 제한 저항을 연결하세요. 공통 양극형 LED라면 출력 논리를 반전해야 할 수 있습니다.
- 부저 모듈의 전압과 전류 사양을 확인하세요. GPIO 직접 구동 범위를 넘는 부저는 트랜지스터 드라이버를 사용합니다.
- 모든 모듈과 ESP32의 GND를 공통으로 연결하세요.

## 업로드 및 실행

1. IR 송신기와 수신기를 서로 마주 보게 배치하고 빔이 수신기에 닿도록 정렬합니다.
2. Arduino IDE에서 ESP32 보드와 포트를 선택해 스케치를 업로드합니다.
3. 시리얼 모니터를 **115200 baud**로 엽니다.
4. 정상 대기 상태에서는 초록색 LED와 `SYSTEM READY` 메시지를 확인합니다.
5. 빔을 손이나 물체로 가립니다. `TRIPWIRE HIT`, 빨간색 LED, 경고음이 발생해야 합니다.
6. 빔을 다시 연결하면 `BEAM RESTORED`가 출력되고 LED가 초록색으로 바뀝니다.

## 동작 원리

`checkIRBeam()`은 IR 송신 핀에서 38 kHz 신호를 발생시키고 약 3 ms 동안 수신기 출력을 확인합니다. 검사 구간 중 수신기에서 `LOW`를 한 번이라도 읽으면 `beamDetected`가 `true`가 됩니다. `loop()`는 현재 값과 이전 값을 비교해 연결→차단과 차단→복구 전환을 감지합니다.

경고음은 Active buzzer를 켠 상태에서 Passive buzzer로 1 kHz와 1.8 kHz 음을 번갈아 재생합니다. 이 함수는 약 600 ms 동안 `delay()`를 사용하므로 경고음이 재생되는 동안 빔 상태를 새로 검사하지 않습니다.

## 조정 항목

- 핀 번호: 스케치 상단의 `#define` 값
- 송신 변조 주파수: `tone(IR_TX_PIN, 38000)`
- 수신 검사 구간: `checkIRBeam()`의 `3000` 마이크로초
- 반복 검사 간격: `loop()`의 `delay(50)`
- 경고음 주파수와 길이: `alarmSound()` 내부의 `tone()` 및 `delay()` 값
- 수신 극성: `digitalRead(IR_RX_PIN) == LOW` 조건

## 동작상 주의

`previousBeam`은 처음에 `true`로 설정되어 있습니다. 따라서 장치를 켰을 때 빔이 차단되어 있거나 첫 검사에서 수신이 실패하면 바로 `TRIPWIRE HIT`가 발생할 수 있습니다. 전원을 켜기 전에 송신기와 수신기를 정렬하세요.

이 예제는 간단한 시연용 경보 회로입니다. 물리적 보안이나 안전 기능이 필요한 용도에는 사용하지 마세요.
