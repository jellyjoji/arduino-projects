# Smart Safe — ESP32 Servo Lock Prototype

ESP32, 조이스틱, 확인 버튼, 도어 스위치, MG996R 서보를 사용한 비밀번호 입력형 금고 잠금 프로토타입입니다. 조이스틱으로 숫자를 선택하고 4자리 비밀번호를 입력한 뒤 확인 버튼을 누르면, 비밀번호가 맞을 때 서보가 잠금 장치를 열었다가 다시 잠급니다.

> 이 코드는 학습·시연용 프로토타입입니다. 비밀번호가 코드에 평문으로 저장되고, 실패 횟수 제한이나 변조 방지 기능이 없습니다. 실제 valuables나 사람의 안전을 보호하는 금고·도어락으로 사용하지 마세요.

## 기능

- 조이스틱 Y축으로 0–9 숫자 선택
- 조이스틱 스위치로 현재 숫자를 4자리 입력에 저장
- 별도 확인 버튼으로 입력값과 정답 비교
- 비밀번호가 맞으면 서보를 열림 위치로 이동
- 비밀번호가 틀리면 부저를 세 번 울림
- 상태에 따라 초록색/파란색 LED 표시
- 도어 스위치가 닫힘 상태를 감지하면 시리얼에 상태 출력

## 준비물

- ESP32 개발 보드
- 아날로그 조이스틱 모듈
- 순간 누름 확인 버튼
- 도어 스위치
- MG996R 서보 모터
- KY-012 등 디지털 on/off 부저 모듈
- KY-016 RGB LED 모듈 중 초록·파랑 채널
- 서보용 별도 5–6 V 전원 공급 장치

## 핀 연결

| 장치             | ESP32 GPIO | 설명                             |
| ---------------- | ---------: | -------------------------------- |
| 조이스틱 X축     |         34 | 현재 코드에서 읽지 않음          |
| 조이스틱 Y축     |         35 | 숫자 증가·감소 입력              |
| 조이스틱 스위치  |         25 | 선택한 숫자 저장, `INPUT_PULLUP` |
| 확인 버튼        |         26 | 비밀번호 확인, `INPUT_PULLUP`    |
| 도어 스위치      |         27 | 닫힘 상태 입력, `INPUT_PULLUP`   |
| 부저             |         12 | 틀린 비밀번호 경고음             |
| KY-016 초록 채널 |          5 | 성공/대기 상태 표시              |
| KY-016 파랑 채널 |         18 | 대기 상태 표시                   |
| MG996R 신호선    |         13 | 잠금 서보 제어                   |

### 전원 및 배선 주의

- **MG996R은 ESP32의 3.3 V 핀에서 전원을 공급하지 마세요.** 서보 정격에 맞는 별도 5–6 V 전원을 사용하고, 서보 전원 GND와 ESP32 GND를 공통으로 연결하세요. 서보는 순간 전류가 커서 보드가 재부팅될 수 있습니다.
- 서보의 신호선만 GPIO13에 연결하고 전원선은 별도 전원에 연결합니다. 실제 서보 선 색상은 제조사에 따라 다를 수 있으니 제품 설명서를 확인하세요.
- 버튼과 스위치는 코드의 `INPUT_PULLUP` 설정에 맞춰 GPIO와 GND 사이에 연결합니다. 눌림/닫힘 상태는 `LOW`로 읽힙니다.
- KY-016 모듈의 공통 단자와 채널 극성에 따라 논리가 달라질 수 있습니다. 현재 코드는 초록·파랑 채널에 `HIGH`를 출력하는 방식으로 작성되어 있습니다.
- GPIO12와 GPIO5는 일부 ESP32 보드에서 부팅 스트랩 동작에 관여할 수 있습니다. 주변 회로가 부팅 시 핀 상태를 강하게 끌어당겨 보드 부팅에 문제가 생기면 부저나 LED를 다른 사용 가능한 GPIO로 옮기고 코드 핀 번호도 변경하세요.

## 소프트웨어 준비

- Arduino IDE 및 ESP32 보드 패키지
- Arduino Library Manager의 **ESP32Servo** 라이브러리

## 비밀번호 입력 및 실행

현재 정답은 스케치의 다음 배열에 고정되어 있습니다.

```cpp
int correctPassword[4] = {2, 5, 8, 3};
```

1. 스케치를 업로드하고 시리얼 모니터를 **115200 baud**로 엽니다.
2. 조이스틱을 위/아래로 움직여 현재 숫자를 선택합니다. Y값이 3000보다 크면 숫자가 증가하고, 1000보다 작으면 감소합니다.
3. 조이스틱 스위치를 눌러 숫자를 저장합니다. 저장 후 다음 숫자는 0부터 시작합니다.
4. 네 숫자를 입력한 뒤 확인 버튼을 누릅니다.
5. 정답이면 `PASSWORD OK`가 출력되고 서보가 90도로 이동합니다. 코드상 약 4초(열림 대기 3초 + 확인 후 대기 1초) 뒤 잠금 위치로 돌아옵니다.
6. 오답이면 `WRONG PASSWORD`가 출력되고 부저가 세 번 울린 뒤 입력값이 초기화됩니다.

서보의 `10°` 잠금 위치와 `90°` 열림 위치는 장착 기구에 맞춰 조정해야 합니다. 기구적 걸림이 생기지 않도록 서보를 분리한 상태에서 동작 각도를 먼저 확인하세요.

## LED와 문 스위치 동작

- 대기 상태: 파랑 채널 ON, 초록 채널 OFF
- 비밀번호 정답: 초록 채널 ON, 파랑 채널 OFF
- 확인 처리 후 약 1초 뒤 서보 잠금과 파란 대기 상태로 복귀
- 도어 스위치 입력이 `LOW`이면 `DOOR CLOSED`를 출력합니다.

현재 코드는 문 스위치가 열렸을 때 별도 메시지를 출력하지 않습니다. `doorCheck()`는 닫힘 입력을 감지하면 500 ms 대기 후 닫힘 메시지를 반복 출력합니다.

## 조정할 값

- 비밀번호: `correctPassword`
- 숫자 증가·감소 임계값: `joystickRead()`의 3000 및 1000
- 조이스틱 반복 속도: `joystickRead()`의 `delay(300)`
- 잠금/열림 각도: `lockDoor()`와 `openDoor()`의 `lockServo.write()` 값
- 열림 유지 시간: `openDoor()`의 `delay(3000)`
- 부저 횟수 및 길이: `buzzerAlarm()`의 반복 횟수와 `delay(300)`

## 알려진 제한과 보안 참고

- 비밀번호는 펌웨어 안에 평문으로 포함되어 있어 물리적·소프트웨어적으로 안전하지 않습니다.
- 오답 횟수 제한, 입력 지연, 비밀번호 변경 기능, 상태 저장/감사 로그가 없습니다.
- 조이스틱·버튼 처리는 `delay()`를 사용하므로 반응이 잠시 멈출 수 있습니다.
- `JOY_X`는 선언되어 있지만 사용하지 않습니다.
- 부팅 시 `lockDoor()`가 서보를 10도로 이동시키므로 잠금 장치가 연결된 상태에서 기구가 안전하게 움직이는지 먼저 확인하세요.
