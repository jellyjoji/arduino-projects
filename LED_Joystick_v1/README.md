# Joystick-Controlled LED Matrix

ESP32의 KY-023 조이스틱 입력을 16×16 WS2815 LED 패널에 방향 화살표로 표시하는 프로젝트입니다. KY-027 모듈의 디지털 신호가 활성화된 동안에는 선택된 화살표를 흰색으로 표시합니다.

## 기능

- 부팅 시 조이스틱 중심값 자동 보정
- 데드존을 적용해 중앙 부근의 흔들림 무시
- 상하좌우 중 가장 큰 축 하나를 선택해 방향 판정
- 방향별 화살표 색상 표시
- KY-027 신호 활성화 시 방향 화살표를 흰색으로 강조
- WS2815 패널의 지그재그 배선, 좌우·상하 반전 설정 지원
- 시리얼 모니터에 조이스틱 값, 방향, 센서 상태, 버튼 상태 출력

## 하드웨어

- ESP32 개발 보드
- 16×16 WS2815 LED 패널 또는 스트립 기반 매트릭스 (총 256 LED)
- KY-023 조이스틱
- KY-027 Magic Light Cup 모듈의 디지털 출력
- LED 패널 사양에 맞는 별도 전원 공급 장치
- 공통 GND 및 필요한 경우 데이터 레벨 시프터

## 핀 연결

| 부품          | ESP32 GPIO | 설명                        |
| ------------- | ---------: | --------------------------- |
| WS2815 DATA   |         18 | FastLED 데이터 출력         |
| KY-023 X      |         34 | X축 아날로그 입력           |
| KY-023 Y      |         35 | Y축 아날로그 입력           |
| KY-023 SW     |         32 | 스위치 입력, 내부 풀업 사용 |
| KY-027 SIGNAL |         27 | 디지털 트리거 입력          |

### 전원·배선 주의

- WS2815 패널은 외부 전원이 필요합니다. 패널의 정격 전압을 확인하고, USB나 ESP32의 5V 핀에서 패널 전원을 공급하지 마세요.
- LED 전원 공급 장치의 GND와 ESP32 GND를 공통으로 연결해야 데이터 신호 기준이 맞습니다.
- ESP32는 3.3V 로직입니다. WS2815 데이터 입력의 논리 임계값에 따라 3.3V 신호가 안정적으로 인식되지 않을 수 있으므로, 호환되는 레벨 시프터를 사용하고 데이터 라인 배선은 짧게 유지하는 편이 안전합니다.
- 패널 최대 밝기에서 필요한 전류를 산정해 전원 공급 장치와 배선 굵기를 정하세요. 코드는 밝기를 40으로 제한하지만, 전원 설계는 LED 수와 실제 색상 패턴을 고려해야 합니다.
- GPIO 34와 35는 ESP32에서 입력 전용 핀이며 내부 풀업/풀다운을 지원하지 않습니다. 조이스틱 X/Y 출력을 연결하고 필요 시 외부 회로로 입력 상태를 안정화하세요.

## 소프트웨어 준비

- Arduino IDE 또는 호환 ESP32 개발 환경
- ESP32 보드 패키지
- Arduino Library Manager에서 설치한 **FastLED** 라이브러리

## 업로드 및 실행

1. 패널의 실제 데이터 시작 위치와 전원 방향을 확인합니다.
2. 스케치 상단의 GPIO, 패널 크기, LED 수를 실제 배선에 맞춥니다.
3. Arduino IDE에서 ESP32 보드와 포트를 선택해 업로드합니다.
4. 전원을 켤 때 약 0.5초 동안 조이스틱을 중앙에 놓습니다. 이 시간에 중심값을 100회 측정해 보정합니다.
5. 시리얼 모니터를 **115200 baud**로 열어 X/Y 값과 방향 판정을 확인합니다.
6. 조이스틱을 움직이면 방향 화살표가 나타납니다. KY-027 신호가 활성화되면 화살표가 흰색으로 강조됩니다.

## 방향과 색상

| 방향                    | 화살표 색상 |
| ----------------------- | ----------- |
| 위                      | 파랑        |
| 아래                    | 빨강        |
| 왼쪽                    | 초록        |
| 오른쪽                  | 노랑        |
| 중앙                    | 표시 없음   |
| 센서 활성화 + 방향 입력 | 흰색        |

조이스틱 버튼은 현재 시리얼 모니터에 `PRESSED` 또는 `RELEASED`로만 출력하며, LED 표시 동작을 바꾸지는 않습니다.

## 패널 방향 보정

스케치 상단 설정을 실제 패널 배선에 맞춰 조정합니다.

```cpp
bool SERPENTINE = true;
bool FLIP_X = false;
bool FLIP_Y = false;
bool FIRST_ROW_REVERSED = false;
```

- 패널이 행마다 진행 방향을 바꾸는 배선이면 `SERPENTINE = true`
- 좌우가 거울처럼 뒤집혔으면 `FLIP_X = true`
- 상하가 뒤집혔으면 `FLIP_Y = true`
- 첫 번째 행의 데이터 진행 방향이 반대라면 `FIRST_ROW_REVERSED = true`

방향이 반대로 입력되면 `INVERT_X` 또는 `INVERT_Y`를 변경합니다. 중앙에서 너무 민감하거나 둔하면 `DEAD_ZONE` 값을 조정하세요.

## 동작 메모

- 조이스틱 ADC는 `analogReadResolution(12)`로 0–4095 범위를 사용합니다.
- 방향은 중앙 보정값과의 차이를 계산한 뒤, 데드존 바깥에서 변화량이 더 큰 축을 선택합니다. 대각선 방향은 별도로 표시하지 않습니다.
- `loop()`는 50 ms 간격으로 동작하므로 명목상 약 20회/초 갱신입니다.
- KY-027 입력은 `KY027_ACTIVE_LEVEL`과 일치할 때 활성으로 판단합니다. 모듈 논리가 반대면 `HIGH`를 `LOW`로 바꾸세요.
- KY-027의 디지털 출력만 사용합니다. 모듈의 아날로그 출력이나 기울기 측정값은 이 코드에서 읽지 않습니다.

## 문제 해결

| 증상                           | 확인할 항목                                                    |
| ------------------------------ | -------------------------------------------------------------- |
| 패널이 켜지지 않음             | 외부 전원, 공통 GND, 데이터 방향 화살표, GPIO18, FastLED 설정  |
| 화살표가 엉뚱한 위치에 표시됨  | `SERPENTINE`, `FLIP_X`, `FLIP_Y`, `FIRST_ROW_REVERSED`         |
| 조이스틱 방향이 반대           | `INVERT_X`, `INVERT_Y`                                         |
| 중앙에서도 방향이 계속 바뀜    | 부팅 중 조이스틱을 고정하고 `DEAD_ZONE`을 높임                 |
| KY-027 상태가 반대로 동작      | `KY027_ACTIVE_LEVEL`을 `LOW`로 변경                            |
| LED가 깜빡이거나 색이 불안정함 | 패널 전원 용량, GND 공통 연결, 데이터 배선 길이 및 레벨 시프터 |
