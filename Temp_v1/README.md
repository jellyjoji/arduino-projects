# Smart Greenhouse — DHT11 Monitoring Prototype

ESP32에서 DHT11 온도·습도 값을 읽고 시리얼 모니터에 출력하는 스마트 온실 프로토타입입니다. 스케치에는 온도·습도 기준값과 릴레이 핀이 선언되어 있지만, 전달된 코드의 릴레이 제어 구간이 손상되어 있어 현재 상태 그대로는 컴파일하거나 자동 제어할 수 없습니다.

## 현재 코드 상태

제공된 코드에는 다음 문제가 있습니다.

- 릴레이 제어 주석 뒤에 `Multi Sensor Challenge Game`, `sdknsladnl`, `Multi Sensor Challenge` 같은 코드가 아닌 문구가 포함되어 있어 컴파일 오류가 발생합니다.
- `TEMP_LIMIT`(27.5°C)와 `HUM_LIMIT`(70%)는 선언만 되어 있고 실제 조건문에서 사용되지 않습니다.
- 릴레이는 `setup()`에서 `LOW`로 초기화됩니다. 손상된 제어 구간을 제외하면 온도나 습도에 따라 켜는 동작은 코드에 없습니다.
- 전달된 구간에는 의도한 제어 조건과 릴레이 ON 동작이 빠져 있습니다.

따라서 이 README는 센서 모니터링의 의도와 하드웨어 구성을 설명하지만, **자동 온실 제어의 실행이 완료되었다고 간주하지 않습니다.** 사용 전에 스케치의 손상된 구간을 복구하고 릴레이 ON/OFF 조건을 구현해야 합니다.

## 하드웨어 구성

- ESP32 개발 보드
- DHT11 온습도 센서
- 릴레이 모듈
- 릴레이로 제어할 저전압 장치(예: 팬) — 선택 사항

## 핀 연결

| 부품           |            ESP32 GPIO | 설명                    |
| -------------- | --------------------: | ----------------------- |
| DHT11 DATA     |                     4 | 온도·습도 디지털 데이터 |
| 릴레이 모듈 IN |                    26 | 릴레이 제어 출력        |
| DHT11 VCC/GND  | 보드·센서 사양에 맞춤 | 전원 및 공통 접지       |
| 릴레이 VCC/GND |      모듈 사양에 맞춤 | 릴레이 모듈 전원        |

DHT11 모듈 종류에 따라 DATA 풀업 저항이 내장되어 있지 않을 수 있습니다. 사용 모듈의 회로와 데이터시트를 확인하세요. 릴레이 모듈의 입력 극성도 확인해야 합니다. 코드는 `LOW`를 OFF로 가정하지만, 일부 모듈은 active-low 입력이라 실제 동작이 반대일 수 있습니다.

> 릴레이로 AC 전원이나 고전압 부하를 제어하는 경우 감전·화재 위험이 있습니다. 정격에 맞는 절연된 모듈과 안전한 enclosure를 사용하고, 전원 배선 작업은 자격과 안전 절차를 갖춘 사람이 수행해야 합니다. 처음 테스트할 때는 저전압 부하를 사용하세요.

## 소프트웨어 준비

- Arduino IDE 및 ESP32 보드 지원 패키지
- Arduino Library Manager의 **DHT sensor library**
- 해당 라이브러리의 의존 라이브러리 **Adafruit Unified Sensor**

## 의도된 프로그램 흐름

1. ESP32가 DHT11을 초기화하고 릴레이 출력을 LOW로 설정합니다.
2. 2초마다 온도와 습도를 읽습니다.
3. 읽기에 실패하면 `DHT SENSOR ERROR`를 출력하고 다음 측정으로 넘어갑니다.
4. 유효한 측정값을 시리얼 모니터에 출력합니다.
5. 온도·습도 기준에 따라 릴레이를 제어하려는 목적이지만, 그 조건은 전달된 코드에 구현되어 있지 않습니다.

## 설정값

| 상수         |      값 | 현재 상태                 |
| ------------ | ------: | ------------------------- |
| `DHTPIN`     |  GPIO 4 | 사용됨                    |
| `DHTTYPE`    |   DHT11 | 사용됨                    |
| `RELAY_PIN`  | GPIO 26 | 출력으로 초기화됨         |
| `TEMP_LIMIT` |  27.5°C | 선언만 됨, 비교 로직 없음 |
| `HUM_LIMIT`  |     70% | 선언만 됨, 비교 로직 없음 |
| 측정 간격    | 2000 ms | 사용됨                    |

## 다음에 구현할 항목

- 컴파일 오류 텍스트를 제거하고 릴레이 제어 구간 복구
- 온도 또는 습도 중 어느 조건에서 릴레이를 켤지 결정
- 릴레이 모듈의 active-high/active-low 동작 확인
- 임계값 주변에서 릴레이가 빠르게 반복 전환되지 않도록 히스테리시스 추가
- 센서 오류 시 릴레이를 안전한 상태로 둘 정책 결정
- 릴레이 ON/OFF 상태를 시리얼에 실제 출력 상태와 함께 기록
