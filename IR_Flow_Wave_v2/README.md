# IR Flow Wave — Proximity Reactive LED Installation

ESP32와 HC-SR04 초음파 센서로 손의 접근을 감지해, RGBW LED 스트립의 흐름 효과와 16×16 WS2815 패널의 중심 파장 효과를 순서대로 실행하는 인터랙티브 조명 프로토타입입니다.

## 동작 시퀀스

1. 손이 센서에서 **15 cm 안쪽**으로 들어오면 시퀀스가 시작됩니다.
2. RGBW 스트립이 약 **1.4초** 동안 청록·파랑에서 흰색으로 밝아지는 pulse/shimmer 효과를 냅니다.
3. 스트립은 약 **0.5초** 동안 밝게 유지된 뒤 꺼집니다.
4. 16×16 패널 중앙에서 파장이 퍼지고 색상이 변하는 효과를 약 **2.2초** 표시합니다.
5. 패널이 꺼지고 약 **0.5초** 뒤 대기 상태로 돌아옵니다.
6. 손이 **20 cm보다 멀어지는 유효 거리 측정값**이 들어오면 다음 트리거를 허용합니다.

## 하드웨어

- ESP32 개발 보드
- 5선 RGBW LED 스트립 (R/G/B/W PWM 채널 + 공통 전원)
- 16×16 WS2815 패널 (256 pixels, 12 V 계열)
- HC-SR04 초음파 거리 센서
- 외부 LED 전원 공급 장치
- RGBW 스트립 채널용 MOSFET 드라이버 또는 적절한 LED 컨트롤러
- HC-SR04 ECHO용 전압 분배기 또는 3.3 V 레벨 변환 회로

## 핀 연결

| 부품/신호     | ESP32 GPIO | 용도                |
| ------------- | ---------: | ------------------- |
| WS2815 DATA   |         18 | FastLED 패널 데이터 |
| RGBW 스트립 R |         23 | PWM 채널            |
| RGBW 스트립 G |         17 | PWM 채널            |
| RGBW 스트립 B |         16 | PWM 채널            |
| RGBW 스트립 W |         19 | PWM 채널            |
| HC-SR04 TRIG  |         21 | 초음파 트리거 출력  |
| HC-SR04 ECHO  |         22 | 거리 펄스 입력      |

## 전원 및 전기적 주의

- **ESP32 GPIO로 LED 스트립이나 패널의 전류를 직접 공급하지 마세요.** 외부 전원을 사용하고 RGBW 스트립 각 채널은 정격 전류에 맞는 MOSFET/드라이버를 통해 구동해야 합니다.
- WS2815 패널 전압과 전류 요구량을 확인하고, 256개 픽셀의 최악 조건을 감당할 수 있는 전원과 배선을 사용하세요. 패널 GND와 ESP32 GND는 공통으로 연결합니다.
- RGBW 스트립의 5선 배선에서 공통선과 채널 극성(공통 애노드/캐소드)을 확인하세요. 현재 `STRIP_INVERTED = true`는 `ledcWrite()`의 듀티를 반전해 출력하는 설정입니다. 실제 드라이버 회로의 active-high/active-low 논리에 맞춰 조정해야 합니다.
- HC-SR04 ECHO는 일반적으로 5 V 신호를 출력합니다. ESP32 입력은 3.3 V 로직이므로 **ECHO를 GPIO22에 직접 연결하지 말고 전압 분배기나 레벨 시프터를 사용하세요.**
- 초음파 센서의 측정 범위는 코드에서 2–400 cm로 제한하지만, 실제 모듈·표면·설치 각도에 따라 측정 가능 거리가 달라집니다.

## 소프트웨어 준비

- Arduino IDE 및 **ESP32 Arduino Core 3.x**
- Arduino Library Manager의 **FastLED** 라이브러리
- `ESP32Servo` 라이브러리는 사용하지 않습니다.

이 스케치는 Core 3.x의 `ledcAttach(pin, frequency, resolution)` API를 사용합니다. Core 2.x 환경에서는 PWM 초기화 코드가 맞지 않을 수 있습니다.

## 업로드 및 실행

1. 패널, RGBW 스트립 드라이버, 센서 전원과 ESP32 GND를 올바르게 공통 연결합니다.
2. 코드의 GPIO가 실제 배선과 맞는지 확인합니다.
3. ESP32 보드와 포트를 선택하고 스케치를 업로드합니다.
4. 시리얼 모니터를 **115200 baud**로 열어 `LED Fighter READY`를 확인합니다.
5. 손을 센서 앞 15 cm 안으로 가져와 스트립 흐름과 패널 파장 시퀀스를 확인합니다.
6. 다시 작동시키려면 센서가 손을 20 cm보다 멀리 있는 유효 거리로 측정한 뒤 다시 가까이 접근해야 합니다.

## 설정값

| 설정                  |  기본값 | 의미                           |
| --------------------- | ------: | ------------------------------ |
| `TRIGGER_DISTANCE`    |   15 cm | 이 거리보다 가까우면 시작      |
| `RESET_DISTANCE`      |   20 cm | 이 거리보다 멀면 재트리거 허용 |
| `STRIP_FLOW_DURATION` | 1400 ms | 스트립 흐름 애니메이션 길이    |
| `STRIP_HOLD_DURATION` |  500 ms | 스트립 끝 도달 후 유지 시간    |
| `PANEL_DURATION`      | 2200 ms | 패널 파장 애니메이션 길이      |
| `FINISH_DELAY`        |  500 ms | 종료 후 대기 시간              |
| `SENSOR_INTERVAL`     |   60 ms | 센서 측정 간격                 |
| `STRIP_INTERVAL`      |   16 ms | 스트립 밝기 업데이트 간격      |
| `PANEL_INTERVAL`      |   25 ms | 패널 업데이트 간격             |

## 패널 좌표 매핑

`XY(x, y)`는 16×16 패널의 짝수 행은 왼쪽에서 오른쪽, 홀수 행은 오른쪽에서 왼쪽으로 연결된 **지그재그(serpentine)** 배선을 전제로 합니다. 실제 패널 배선이 다르면 `XY()` 함수를 수정해야 합니다.

## 상태 처리

프로그램은 `IDLE → STRIP_FLOW → STRIP_HOLD → PANEL_WAVE → FINISHED` 상태 머신으로 효과 순서를 관리합니다. 각 단계는 `millis()` 기반 업데이트로 진행되며, `pulseIn()`에는 25 ms 타임아웃이 설정되어 있습니다.

현재 `readDistance()`가 타임아웃 또는 범위 밖 측정값에 `-1`을 반환하면 `updateSensor()`는 기존 `distanceCm` 값을 유지합니다. 따라서 센서가 유효한 20 cm 초과 거리를 읽지 못하면 재트리거가 다시 허용되지 않을 수 있습니다. 빈 에코를 손이 멀어진 것으로 해석하는 기능은 현재 코드에 없습니다.

## 문제 해결

| 증상                                        | 확인할 항목                                                        |
| ------------------------------------------- | ------------------------------------------------------------------ |
| 센서가 반응하지 않음                        | TRIG/ECHO 배선, 공통 GND, ECHO 레벨 변환, 시리얼 출력              |
| 효과가 한 번만 실행됨                       | 20 cm 초과의 유효한 거리값이 측정되는지 확인                       |
| RGBW 스트립이 반대로 동작하거나 꺼지지 않음 | `STRIP_INVERTED`, 스트립 공통 극성, MOSFET 드라이버 논리           |
| WS2815 색상/위치가 이상함                   | GRB 색상 순서, GPIO18 데이터 방향, 패널 serpentine 배선, 전원 용량 |
| ESP32가 재부팅되거나 LED가 깜박임           | LED 외부 전원 용량, 전원 배선, 공통 GND, 데이터 레벨 시프팅        |
