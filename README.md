# Arduino & ESP32 Projects

Arduino와 ESP32를 이용해 센서, 액추에이터, 조명, 사운드를 연결하고 동작을 실험한 프로젝트 모음입니다. 각 프로젝트에서 하드웨어 입력을 읽고, 코드로 상태를 판단한 뒤 LED·부저·서보·디스플레이 등으로 결과를 표현하는 과정을 정리합니다.

## 프로젝트 모음

| 프로젝트              | 주요 기능                                             | 주요 기술                                |
| --------------------- | ----------------------------------------------------- | ---------------------------------------- |
| IR Invisible Tripwire | 적외선 빔이 차단되면 LED와 부저로 경보                | ESP32, IR 송수신, 상태 전환              |
| Touch Sensor Piano    | 터치 입력으로 음을 연주하고 색상 피드백 제공          | ESP32 터치 입력, 부저, RGB LED           |
| Joystick LED Matrix   | 조이스틱 방향을 LED 매트릭스의 화살표로 표시          | ESP32, 조이스틱, WS2815 LED 패널         |
| IR Flow Wave          | 손의 접근에 반응해 LED 스트립과 패널에 빛의 흐름 연출 | ESP32, 초음파 센서, RGBW LED, WS2815     |
| Smart Safe            | 비밀번호 입력 결과에 따라 서보 잠금 프로토타입 제어   | ESP32, 조이스틱, 버튼, 서보, 도어 스위치 |
| Smart Greenhouse      | 온도·습도를 읽고 시리얼 모니터에 표시하는 프로토타입  | ESP32, DHT11, 센서 데이터 읽기           |

## 공통으로 다루는 내용

- 센서 입력값을 읽고 조건에 따라 동작을 바꾸는 임베디드 로직
- LED, 부저, 서보, LED 매트릭스 등 출력 장치 제어
- 하드웨어 연결과 핀 설정, 시리얼 모니터를 이용한 확인
- 센서와 액추에이터를 결합한 인터랙션 프로토타이핑

## 사용 방법

1. 저장소에서 관심 있는 프로젝트 폴더를 엽니다.
2. 해당 프로젝트의 README에서 부품, 핀 연결, 라이브러리 요구사항을 확인합니다.
3. 스케치를 Arduino IDE에서 열고 사용하는 보드와 포트를 선택한 뒤 업로드합니다.
4. 시리얼 모니터가 필요한 프로젝트는 README에 적힌 속도(baud rate)로 설정합니다.

프로젝트별 부품과 라이브러리, 핀 배치는 서로 다를 수 있으므로 각 프로젝트의 안내를 먼저 확인하세요. 전원 연결 시에는 센서와 모듈의 정격 전압을 확인하고, 서보나 LED 스트립처럼 전류가 큰 부품은 적절한 외부 전원을 사용하세요.

## 프로젝트 상태 안내

이 저장소에는 기능 검증용 프로토타입과 학습 프로젝트가 함께 있습니다. 각 README에 구현된 기능과 알려진 제한을 구분해 기록하며, 일부 아이디어는 아직 완성된 제품이 아니라 실험 단계입니다. 예를 들어 Smart Greenhouse는 현재 제공된 스케치에서 온도·습도 측정과 출력이 중심이며 릴레이 자동 제어는 완성되지 않았습니다.
